# StudySteps Product Roadmap

The roadmap protects the V1 learning model while increasing support in controlled stages. Dates are intentionally omitted; sequencing depends on evidence and capacity.

## V1 — Frozen portfolio build

- Concept, worksheet/problem, and project-specific help
- Teach Before Answer and explicit answer reveal
- Text, supported photo, and voice input
- Read to Me
- Project Launchpad
- Done & Due and local persistence
- Limited validated source support

## V1.1 — Smarter study scheduling

- Suggest study windows from due date, remaining steps, and estimated effort
- Improve reminder timing and urgency cues
- Preserve student control over schedules and reminders

## V1.2 — Adaptive understanding checks

- Adjust follow-up questions based on student attempts
- Identify likely misconceptions without high-stakes grading claims
- Measure whether the student wants more explanation, practice, or challenge

## V2 — Broader grounded research

- Expand verified-source coverage with explicit provenance
- Add retrieval-augmented generation from student-provided class materials
- Preserve source boundaries, citations, and unsupported-topic messaging
- Add privacy and retention controls for uploaded materials

## V3 — Learning memory and personalization

- Remember preferences and learning progress with informed consent
- Provide transparent controls to inspect, correct, and delete learning data
- Apply age-appropriate privacy, retention, and guardian considerations
- Avoid permanent labels based on limited performance

## V4 — Guardrailed agentic study coach

- Coordinate planning, practice, reflection, and reminders
- Require approval for consequential actions
- Preserve Teach Before Answer and source-verification policies
- Provide clear activity history, controls, and safe stopping points

## Explicit V1 non-goals

- LMS integrations
- Parent or teacher portals
- Automatic submission
- Accounts and cloud sync
- Open-ended web research
- Autonomous action on a student’s behalf
