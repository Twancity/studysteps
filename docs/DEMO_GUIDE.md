# StudySteps V1 Demo Guide

Use these scenarios to demonstrate the product in a short portfolio review or interview.

## Demo 1 — Learn a concept

**Student request:**  
“I want to understand multiplication for a 3rd grader.”

### What to demonstrate

- Typed or Tell StudySteps voice input
- Grade-appropriate explanation
- Equal groups / repeated addition / array example
- Guided practice
- Hint before final answer
- Check My Answer
- Show Answer only after explicit student action
- Read to Me

### PM point

The product optimizes for **learning progression**, not answer speed.

---

## Demo 2 — Photograph a worksheet

Use a clear worksheet image, such as a missing-addend addition problem.

### What to demonstrate

- Camera, file picker, or drag-and-drop
- Real photo understanding
- Editable “Here’s what I found in your photo” review
- Skill identification
- Different worked example
- Progressive hints
- Solve One With Me
- Explicit final-answer reveal

### PM point

This flow came directly from testing that exposed an early failure: uploaded photos were initially only previews and did not influence the AI response.

---

## Demo 3 — Start a project

**Example:** Water Cycle model or Civil Rights Movement digital exhibit.

### What to demonstrate

- Assignment understanding
- Project Launchpad
- Multiple project directions
- Student choice
- Resource/citation support when validated
- Editable personalized plan
- Deliverables
- Done & Due integration

### PM point

The product does not jump directly from assignment text to a generic checklist. It supports:

**Understand → Explore → Choose → Plan → Build → Track**

---

## Demo 4 — Done & Due

Use an assignment with several deliverables.

### What to demonstrate

- Due date
- Turn-in checklist
- Next unfinished step
- Ready to Turn In
- Turned In
- “You finished this, but did you turn it in?” behavior
- 30-day completed-work cleanup policy

### PM point

A key product insight was that **completing work and submitting work are different user problems**.

---

## Suggested interview narrative

1. Start with the student problem.
2. Show one failed early assumption.
3. Explain the product decision that followed.
4. Demonstrate the improved flow.
5. Close with the V1 constraints and roadmap.

Keep the demo focused on product judgment, not just feature count.
