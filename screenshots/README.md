## Portfolio guidance

The root [README](../README.md) uses the strongest screenshots as a visual product walkthrough.

These images represent the frozen V1 product state. Earlier screenshots showing generic fallback behavior or disconnected photo understanding are intentionally excluded from the main walkthrough; those failures are documented in the [Product Case Study](../docs/PRODUCT_CASE_STUDY.md) as iteration evidence.
